# Что делает проект?
Помогает быстро создать и развернуть на сервере бота, который будет отправлять
пользователям цепочки сообщений через определенные промежутки времени (например, раз в день). 
Человек оплачивает цифровой продукт и получает заранее подготовленный вами контент.

Платежи принимаются в Telegram Stars. Если нужно адаптировать
бота под продажу физических продуктов, подключите платежную систему в Telegram (это можно сделать через @BotFather). 
Затем зайдите в `my_bot/payments.py` и [измените bot.send_invoice](my_bot/timing/payments.py): 
укажите другие `currency` и `provider_token`. Если вы продаете цифровой продукт, менять ничего не нужно.
# Как работать с проектом?
## Переименуйте файл .env.example в .env и заполните его
Файл лежит в папке `my_bot`. Каждый пункт прокомментирован =)
Те, кто включен в список админок, смогут по кодовому слову или фразе (которую вы сами укажете в .env) зайти в "админку". 
Админам доступна информация из БД: сколько человек оформили покупку, кто именно, сколько вы суммарно заработали.

## Измените файл config.py
Укажите название, описание, цену вашего продукта, телеграм-эффект при покупке,
список команд в меню бота. 

**Обратите внимание:** по правилам телеграм, команда paysupport должна быть обязательно!

**Важно:** бот настроен так, чтобы сообщения отправлялись каждый будний день. Если вы хотите это изменить, 
[откройте time_functions.py в папке timing](my_bot/timing/time_functions.py) и исправьте строку 20.

## Измените файл `my_bot/keyboards/inline_keys.py`
В нем есть функция `keyboard_with_links`. Она прикрепляет клавиатуру к стартовому сообщению, чтобы пользователи 
могли видеть нужные вам ссылки: например, контакты, 
ссылку на сайт, тг-канал и так далее. Это полезно для продаж: дайте людям возможность поближе с вами познакомиться 
перед покупкой. Кнопок со ссылками можно сделать сколько угодно.

Если у вас есть непреодолимое желание отключить клавиатуру, зайдите в [my_bot/handlers/user_handlers.py](my_bot/handlers/user_handlers.py) и в функции 
`cmd_start` удалите `reply_markup=keyboard_with_links()`.

## Измените файл messages.py в папке my_bot/handlers
Сюда вы добавите тот контент, который увидят в боте покупатели.

В классе Messages есть три метода, которые вы будете использовать:
- `send_text(chat_id, text='Текст сообщения')`. Текст форматируется в HTML.
- `send_file(chat_id, file_id, file_path, caption)`. Отправляет картинку/файл.
- `send_album(chat_id, files_id, files_path, caption)`. Отправляет альбом с картинками в формате .jpg/.png.

В функции `message_day_1` приведен пример, опирайтесь на него. В каждую цепочку (день 1, день 2 и пр.) можно добавить сколько угодно фото, альбомов, текстов. Бот отправит их один за другим в том порядке, в котором вы их выстроите.

### Как добавить файлы
В my_bot есть папка screens. Вы можете положить файлы в нее или создать свою папку. Используйте удобные для проекта названия: 
например, day1_1.jpg, day1_2.jpg и т.д. Путь (в формате "screens/day1_1.jpg") нужно указывать в функциях `send_file` 
и `send_album`. Это ваша подстраховка на случай, если телеграм однажды не примет file_id.

Обратите внимание: `send_album()` отправляет альбом с картинками в формате .jpg/.png. 
Если вы хотите отправить, например, .pdf, используйте `send_file`. Кроме того, в альбом влезет не больше 10 картинок, это ограничение телеграма.

**Важно:** телеграм [не примет файлы больше 20 МБ](https://core.telegram.org/bots/api#getfile).

### Откуда взять file_id
Отправьте документ, картинку или видео в бота, он пришлет в ответ `file_id`. Это сработает, только если вы включены 
в список админов в config.py.

Если планируете использовать и другие форматы (аудио, стикеры и пр.), добавьте соответствующие фукнции в [my_bot/handlers/admin_handlers.py](my_bot/handlers/admin_handlers.py) по образу и подобию функций, которые там уже есть.

### Как добавить возврат денег
Если вы планируете оформлять возврат денег, раскомментируйте строку с `self.money_refund_message` и добавьте сообщение, 
а также напишите соответствующую функцию [в user_handlers.py в той же папке](my_bot/handlers/user_handlers.py).

## Что делать, если нужно больше/меньше цепочек сообщений?
[В файле messages.py](my_bot/handlers/messages.py) добавьте или уберите функции `async def message_day_х`. 
Затем исправьте функцию message_chain.
Всё остальное подтянется само.

## Как развернуть бота на сервере
`Dockerfile` и `docker-compose.yml` уже готовы. Нужны минимальные правки: в [docker-compose.yml](docker-compose.yml) 
укажите ваш пароль от Redis и пропишите пути для config.py в volumes. 
Эти пути нужны, чтобы вы могли менять конфигурацию бота, не заходя в контейнер. После перезапуска бот подтянет новую конфигурацию автоматически.

Затем выполните `docker compose up -d`. Всё установится и запустится само.

## Локальная разработка

Для разработки рекомендуется Python версии 3.12 пока aiohttp не начнёт поддерживать версию Python 3.13.

Рекомендуется сразу установить uv - ускоряет и упрощает работу с пакетами:

```bash
pip install uv
```

Для развертывания виртуального окружения с рекомендуемой версией Python:

```bash
uv venv --python 3.12
```

Активация виртуального окружения на Windows:

```bash
.venv\Scripts\activate
```

Деактивация:

```bash
deactivate
```

Установка зависимостей:

```bash
uv pip install -r requirements.txt
```

Проверка синтаксиса:

```bash
ruff check my_bot
```

Или проверка с попыткой исправить (сейчас работает на импортах):

```bash
ruff check my_bot --fix
```
